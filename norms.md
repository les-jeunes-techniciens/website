# Normes du projet

## Langues

- Code: anglais
- Interface utilisateur: français
- README: français
- Commits: français
- Ancres et sections: français sans accents dans les identifiants techniques lorsque nécessaire
- Payloads: anglais pour les clés, français pour les valeurs visibles
- Base de données: non applicable

## Structure

- Application Vue 3 monopage
- Aucune route applicative
- Composants réutilisables dans `src/components`
- Noms de fichiers web en kebab-case
- Variables JavaScript en camelCase

## Qualité

- Code minimal, lisible et maintenable
- Aucune variable inutilisée
- Aucun commentaire inutile
- Texte visible exclusivement en français
- Navigation par ancres avec défilement fluide
- Formulaire avec validation côté client
